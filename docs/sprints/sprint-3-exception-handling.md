- [x] 로딩 및 타임아웃 중에는 사용자 입력창 및 칩 클릭을 완전 비활성화하여 중복 요청 차단

## 3. 테스트 및 검증 기준 (Acceptance Criteria)
1. [x] 50자 이상의 텍스트를 붙여넣었을 때 50자까지만 입력되고 실시간으로 `50/50`이 표시된다.
2. [x] 아무것도 입력하지 않고 전송을 시도하면 경고 툴팁이 뜨며 전송되지 않는다.
3. [x] 질문 및 추천 산출 중 로딩 표시가 명확히 보이며 중복 전송이 방지된다.
4. [x] 강제로 예외가 발생하거나 타임아웃이 발생해도 화면이 깨지지 않고 복구 버튼이 노출된다.
