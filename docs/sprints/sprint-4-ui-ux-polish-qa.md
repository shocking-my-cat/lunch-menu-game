## 2. 세부 개발 태스크 (Tasks)

### Task 4.1: 초기 화면 (Idle) 디자인 완성
- [x] PRD 권장 아트보드 1 준수:
  - 중앙 큰 타이포 문구: **“내가 점심 메뉴 추천해줌”**
  - 메인 액션 CTA 버튼: **“시작하기”** (호버/클릭 마이크로 인터랙션, 펄스 및 그림자 효과)
  - 귀여운 마스코트 일러스트레이션 및 친근한 서브 안내 문구
  - 화면 전체 클릭 또는 CTA 버튼으로 즉각 대화 진입

### Task 4.2: 결과 화면 (Result View) 카드 레이아웃 고도화
- [x] 1순위(Primary), 2순위(Alternative) 추천 메뉴 카드 비주얼 강화
  - 1순위: 골드/프라이머리 뱃지 (“🥇 1순위 추천”)
  - 2순위: 서브 뱃지 (“🥈 2순위 대안”)
  - 메뉴명, 이모지, 태그 칩, 위트 있는 맞춤형 추천 사유(blurb/matchReason) 카드 렌더링
- [x] 피드백 질문 문구: **“추천받은 메뉴가 마음에 들었나요?”**
- [x] 명확한 [Yes] (좋아요, 이걸로 확정!) / [No] (음... 다른 거 없어요?) 버튼 배치

### Task 4.3: 최종 완료 화면 (Done View) 축하 인터랙션
- [x] [Yes] 선택 시 게임 클리어 느낌의 **“축하합니다! 🎉 오늘 점심은 [메뉴명]!”** 문구
- [x] 축하 컨페티(폭죽 파티클) 애니메이션 연출 (`components/lunch/confetti.tsx`)
- [x] 확정된 메뉴 카드 강조 및 "처음부터 다시 추천받기" 버튼 제공

### Task 4.4: 1440×900 데스크톱 환경 및 반응형 최적화
- [x] 데스크톱 1440×900 기준 뷰포트에서 상하 스크롤 튀김 없이 안정적인 카드 프레임 배치
- [x] 모바일/태블릿 등 다양한 화면 크기에서도 깨지지 않는 유연한 max-width 및 레이아웃
- [x] 다크/라이트 모드 대응 및 시각적 일관성 유지

### Task 4.5: 종합 기능 및 예외 QA (Quality Assurance)
- [x] 전체 7턴 정상 플로우 검증
- [x] 재추천(No) → 2턴 추가 질문 → 재추천 결과 플로우 검증
- [x] 5대 예외 처리 케이스 시뮬레이션 검증
