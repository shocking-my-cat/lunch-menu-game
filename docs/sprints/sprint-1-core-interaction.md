# 🏃 Sprint 1: 핵심 대화 인터랙션 & 상태 머신 (Core Interaction)

## 1. 스프린트 개요
- **목표**: PRD 명세에 따른 대화형 스무고개 상태 머신(State Machine) 확립 및 턴 전환 대화 인터랙션 구축
- **기간/우선순위**: P0 (필수 기반 작업)
- **상태**: ✅ **완료 (Completed)**
- **관련 PRD 항목**: `REQ-01`, `REQ-02`, `REQ-04`, `REQ-06`, `REQ-09`, `REQ-10`

---

## 2. 세부 개발 태스크 (Tasks)

### Task 1.1: 대화 상태 머신(State Machine) 구조화
- [x] 대화 페이즈 정의 세분화:
  - `idle`: 시작 대기 상태 (메인 화면)
  - `chat`: 사용자 답변 및 AI 질문 턴 진행 상태
  - `recommending`: 메뉴 추천 연산 및 “메뉴 추천 중...” 로딩 상태
  - `result`: 1/2순위 추천 결과 표시 및 피드백 대기
  - `done`: 사용자가 추천 수락 시 성공 화면
- [x] 상태 전이 흐름 및 타이머 이벤트의 메모리 누수 방지(`useEffect` cleanup)

### Task 1.2: 멀티턴 질문 전개 및 동적 질문 큐
- [x] 기본 7턴 질문 시퀀스 구성 (온도/국물 → 매운맛 → 요리 국적 → 주식 종류 → 식사량 → 예산 → 동행 인원)
- [x] 답변 완료 시 다음 질문으로의 부드러운 전환 (타이핑 버블 650ms 연출)
- [x] 메시지 리스트 스크롤 자동 동기화 (`scrollIntoView` / smooth scroll)

### Task 1.3: 대화 입력 인터페이스 고도화
- [x] 빠른 선택 칩(Quick Choice Chips) 클릭 시 즉시 답변 전송
- [x] 자유 텍스트 입력창과 빠른 선택 칩 간의 자연스러운 상호작용
- [x] IME 한글 조합(Composition) 이슈 방지 처리 (Enter 전송 시 중복 호출 방지)

### Task 1.4: 재추천 루프(No 피드백) 처리
- [x] [No] 버튼 클릭 시 이전 추천 메뉴 제외 목록(`excluded`)에 등록
- [x] 라운드 카운터 증가 및 2개 추가 질문(`FOLLOWUP_QUESTIONS`)으로 질문 큐 전환
- [x] "다른 거 없어요?" 사용자의 자연스러운 리액션 메시지 자동 추가 후 AI 후속 질문 전개

## 3. 테스트 및 검증 기준 (Acceptance Criteria)
1. [x] "시작하기"를 누르면 첫 번째 질문이 타이핑 애니메이션과 함께 나타난다.
2. [x] 7개의 질문이 순차적으로 표시되며, 칩 또는 텍스트로 모든 질문에 답변할 수 있다.
3. [x] 7번째 질문 답변 후 `recommending` 상태를 거쳐 결과 화면으로 전이된다.
4. [x] 결과 화면에서 [No]를 누르면 2개의 추가 질문이 이어지고 새 결과가 도출된다.
5. [x] 대화 도중 "처음부터"를 누르면 상태가 완전히 초기화되어 Idle 화면으로 돌아간다.
6. [x] Next.js 프로덕션 빌드 및 HTTP 200 응답 정상 검증 완료.
